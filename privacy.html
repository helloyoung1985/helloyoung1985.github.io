youtube-benchmark Privacy Policy

youtube-benchmark is a personal tool built by the operator of the YouTube channels Malang Footprints and Giljabji to analyze the performance of the operator's own channels.

Data accessed

Only YouTube Analytics data (views, watch time, impressions click-through rate, etc.) of the operator's own Google account, using the read-only scope yt-analytics.readonly. No data from any other user is collected.

Use of data

The data is used only to analyze and improve the content of the operator's own channels.

Sharing

The data is never sold or shared with any third party.

Storage and deletion

Analysis results are kept only in the operator's private repository and can be deleted by the operator at any time.

Revoking access

Access can be revoked at any time in Google Account > Security > Third-party apps and services.

Limited Use

youtube-benchmark's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Effective date: November 20, 2026
